## Estrutura rapida

- Paginas HTML: `frontend/*.html`
- Javascript da interface: `frontend/src/*.js`
- Estilos: `frontend/src/styles/`
- Imagens publicas: `frontend/public/images/`
- Uploads publicos: `frontend/public/uploads/`
- Backend API: `backend/server.js`
- Base de dados SQL: `backend/hexomel_mysql.sql`
- Seeds: `backend/scripts/seed_test_data.sql`
- Scripts antigos/auxiliares arquivados: `scripts/archive/`
- Documentos soltos arquivados: `docs/archive/root-docs/`

## Objetivo desta pasta

- Mostrar o mapa do site
- Mostrar onde ficam os ficheiros publicos
- Dar uma vista rapida da organizacao do projeto
